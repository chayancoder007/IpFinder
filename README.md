✨ Features
🔍 Locate any IP address instantly
🧠 Auto-detect user's IP on load
🌍 Shows city, region, country, and coordinates
🗺️ Interactive live map with Leaflet
🎨 Matrix-style falling code background (Canvas)
🌒 Dark mode with hacker UI
⚡ Smooth animations using Framer Motion
📱 Fully responsive design

📦 Tech Stack
React.js
Axios
IPStack API (Free Tier)
Leaflet + React-Leaflet
Framer Motion
Canvas API (for matrix effect)

How to get start :
open vs code and run thisbelow command in terminal
git clone https://github.com/YOUR_USERNAME/ip-finder-hacker-ui.git
cd ip-finder-hacker-ui
npm install
npm start
